General / Items
QuestbookRead. The. Questbook. It has a LOT of information, including many of the below tips.
Traveller's BeltGives you access to a 2nd Hotbar via a Hotkey. Useful for Misc GT Tools like Soft Mallet, Crowbar, etc.
Traveller's GlovesCan be enhanced with Redstone to give permanent Haste bonus to all Breaking actions.
Item DislocatorFits in all Bauble Slots, and can be toggled via a Hotkey.
Adventure BackpackHas 2 Slots for tools that you can switch to via Shift+Scroll Wheel.
BackpackHas a dedicated slot via the key combo "Shift + Open Backpack". Open via just "Open Backpack" after it's in its slot.
Tinker's Crossbow BoltsFit in Bauble Slots and work with Mending.
Holo GlassesFit in the Mask Slot on the Diamond Chestplate page.
UnbreakingWorks on GC Oxygen Tanks, making them last longer.
Healing AxeFits in the Offhand Slot for permanent hunger regen.
Fast Block PlacingA Hodgepodge mod feature that allows you to place blocks much faster. Activate via its hotkey.
Night VisionEnchantment can be toggled via the "Night Vision" hotkey in the Dark Steel Armor category.
Voiding Drop FilterThe first proper Inventory Void you get — auto deletes items like Cobblestone when picked up.
/home namingList too big? Prefix homes for easier navigation, e.g. /home Dim_TF or /home Vein_Silver. Type /home Dim_ and press Tab to filter.
Machines / Automation
Wires / CablesUse a dedicated color for each different Voltage cable in your base. Lets you easily see the Tier and avoid accidents.
RF ConsumersEnderIO machines, Forestry, etc. can generally connect directly to any voltage GT cable — auto converts to RF.
ScrewdriverRight-click on a machine to allow item input via its Output side. Useful for automation.
Soldering IronWith Solder in inventory: allows multiple stacks of the same item to be input via automation (e.g. Buttons). Useful for automation.
Wire CutterCan connect wires through a machine via Shift+Right Click on the Highlight Grid.
WrenchShift+Right Click on GT Fluid Pipes to lock their flow direction. Prevents backwards flow, lessens lag, and allows faster flow if the pipe is not 100% full.
Quartz Cutting KnifeAllows you to rename all AE2 Blocks. The new name shows in Interface Terminal, WAILA, and Network Tool.
